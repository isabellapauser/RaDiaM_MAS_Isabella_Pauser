# RaDiaM_MAS_Isabella_Pauser
Computational workflows developed for a master’s thesis within the FTI-funded Ra-Dia-M project. The repository covers reproducible transcriptomics and proteomics analysis, differential expression benchmarking, and multi-omics integration to support cancer research and SERS data interpretation.

Start by performing 01_NAguide.R to benchmark 23 different imputation methods and discover the missingess pattern in the melanoma dataset. The output needs to be manually entered into the web based NAguideR application. For analysis standard settings were applied. The manual workflow is described in the appendix of the underlying thesis.
