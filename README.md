## Summary

This repository contains the computational workflows developed for a Master’s thesis conducted within the Ra-Dia-M project at the Biotech Campus Tulln, University of Applied Sciences Wiener Neustadt. The study compares the non-metastatic MCM-1G and metastatic MCM-DLN melanoma cell lines using LC-MS/MS proteomics, RNA-sequencing transcriptomics and surface-enhanced Raman spectroscopy (SERS).

The proteomics workflow processes label-free protein abundance data generated with MaxQuant. Proteins with insufficient observations were removed, and missing values were assessed and imputed using the DreamAI ensemble algorithm. Differential protein abundance was subsequently evaluated using DEqMS, which accounts for the relationship between protein-level variance and the number of peptides or peptide-spectrum matches used for quantification.

Multi-omics integration was performed using DIABLO, implemented in the `mixOmics` R package. The analysis integrates preprocessed proteomic, transcriptomic and SERS data to identify correlated molecular and spectral features that discriminate between MCM-1G and MCM-DLN. Different strategies for selecting informative SERS regions were implemented and evaluated, including sparse-group lasso, a genetic algorithm and a window-selection approach. Sparse-group lasso was selected for the final workflow because it accounts for the strong correlation between neighbouring Raman shifts and enables the selection of interpretable spectral regions.

The repository provides a transparent and reproducible framework for preprocessing, feature selection, differential abundance analysis and supervised multi-omics integration. The resulting features should be regarded as exploratory candidates for melanoma characterization and the future development of SERS-based diagnostic strategies.

## Repository Contents

The repository contains R Markdown workflows for:

- assessment and imputation of missing proteomics values using DreamAI;
- differential protein abundance analysis using DEqMS;
- preprocessing and construction of the proteomic, transcriptomic and SERS data blocks;
- SERS feature selection using sparse-group lasso, genetic algorithms and window selection;
- supervised multi-omics integration using DIABLO;
- model evaluation and generation of figures and result tables.


## Data Availability

The datasets analysed in this project were generated within the Ra-Dia-M project. The repository contains the computational analysis workflows but does not include the complete input datasets. Data will be made available upon reasonable request to david.lilek@fhwn.ac.at.

Proteomic data were generated by label-free LC-MS/MS and quantified using MaxQuant. Transcriptomic data were generated by RNA sequencing and summarized as feature-count matrices. The SERS input consists of preprocessed Raman spectra obtained from MCM-1G and MCM-DLN melanoma cells.


## Reproducibility

The analyses were conducted in R. The main software packages include:

- `DreamAI` for ensemble-based missing-value imputation;
- `DEqMS` and `limma` for differential protein abundance analysis;
- `mixOmics` for DIABLO-based multi-omics integration;
- `DESeq2` for transcriptomic preprocessing;
- `msgl` for sparse-group lasso feature selection;
- `GA` for genetic-algorithm-based feature selection.

Package versions and relevant analysis parameters are documented within the individual R Markdown files. Random seeds were specified for stochastic procedures where applicable.

## Limitations

The analyses are based on two melanoma cell lines with three biological replicates per cell line. Measurement replicates were aggregated before multi-omics integration so that each data block represented the same six biological samples. Consequently, model tuning and performance estimates are based on a small sample size and may be unstable.

DIABLO is a supervised method, and the observed separation between the two cell lines should therefore not be interpreted as independent validation of predictive performance. Moreover, the cell lines share a common patient origin, which limits the generalizability of the identified molecular and spectral signatures to other melanoma models or clinical samples.

The selected proteins, transcripts and SERS regions represent exploratory candidates rather than validated biomarkers. Independent biological cohorts and experimental validation are required before conclusions regarding diagnostic or prognostic utility can be drawn.
